# Souq MR — سوق موريتانيا

واجهة أولية لسوق إلكتروني موريتاني لعرض المنتجات وتصفحها، مع تجربة تسجيل بائع/مشتري وإضافة إعلانات تجريبية.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع على استضافة مواقع ثابتة مثل Vercel.

## الموجود حاليًا
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- البحث والتصفية حسب القسم والمدينة والترتيب حسب السعر.
- بطاقات المنتجات وصفحة تفاصيل المنتج.
- نماذج تجريبية لحساب المشتري والبائع.
- إضافة إعلانات تجريبية وحفظها محليًا في المتصفح.

## مهم قبل الإطلاق الحقيقي
هذه نسخة واجهة تجريبية فقط. الحسابات والمنتجات تحفظ محليًا في المتصفح ولا تمثل مصادقة آمنة أو قاعدة بيانات مشتركة. لا تستخدمها لجمع كلمات مرور حقيقية أو لإتمام معاملات فعلية.

## المرحلة التالية
ربط Supabase للمصادقة وقاعدة البيانات وتخزين صور المنتجات، ثم بناء طلبات الشراء ولوحات تحكم البائع والمشتري، وإضافة سياسات أمان RLS واختبارها قبل الإطلاق.
