# Souq MR — السوق الموريتاني

سوق إلكتروني عربي (RTL) لعرض المنتجات في موريتانيا، مبني بواجهة HTML/CSS/JavaScript وSupabase.

## ما يعمل الآن
- تسجيل حسابات المشترين والبائعين عبر Supabase Auth.
- ملفات تعريف المستخدمين مع نوع الحساب والمدينة ورقم التواصل.
- نشر المنتجات وتصفح المنتجات المنشورة والبحث والتصفية.
- رفع صور المنتجات إلى Supabase Storage (حتى 5MB).
- تسجيل طلبات الشراء مع حفظ السعر وقت الطلب.
- حماية قاعدة البيانات بسياسات Row Level Security (RLS).

## التشغيل
افتح `index.html` عبر استضافة تدعم HTTPS وES modules (مثل Vercel أو Netlify). يتصل التطبيق بمشروع Supabase المهيأ في `app.js` باستخدام عنوان المشروع ومفتاح publishable العام. هذا المفتاح مصمم للاستخدام في المتصفح؛ لا تضع أبدًا service_role أو أسرار الخادم في ملفات الواجهة.

## قاعدة البيانات
تم تطبيق المخطط الأولي عبر migrations:
- `profiles`
- `products`
- `orders`
- `order_items`
- `favorites`
- Storage bucket: `product-images`

## ملاحظات الإطلاق
- يجب تفعيل إعدادات البريد وتحديد Site URL وRedirect URLs في Supabase Auth قبل الإطلاق.
- أضف سياسات تحقق إضافية واختبارات أمنية شاملة قبل استقبال مستخدمين حقيقيين.
- الطلبات تسجل داخل الموقع فقط؛ لا توجد بوابة دفع إلكتروني أو تكامل توصيل حتى الآن. يتم تنسيق الدفع والتسليم خارج الموقع.
- راجع تنبيهات Supabase Security Advisor قبل الإطلاق.
